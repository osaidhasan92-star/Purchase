Import and export company records

Administrator access required. Import is available only on an empty installation.

For browser demo records, open this page in the same browser and on the same origin where the demo was used. If moving domains, use the browser console export instructions in the README, then select that JSON file below.

Imported accounts are disabled until an administrator resets their passwords and activates them. Browser passwords are never imported. JSON exports contain business and HR records; store them privately. Database backups are also needed to restore accounts and audit history.
